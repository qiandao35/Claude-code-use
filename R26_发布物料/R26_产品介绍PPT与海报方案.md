## 0. 结论

1. **同类产品发布的讲法**：大多按这条线讲：
   - 一句话说清它是什么；
   - 它解决谁的什么麻烦；
   - 长什么样、有多大；
   - 里面靠什么做到；
   - 用数字证明；
   - 放在哪用；
   - 规格、价格、上市时间。
2. **R26 现在最有说服力的素材是外观和材质**：尺寸、三种 CMF 的面积占比、工艺、88 颗灯珠、约 1056 个进风孔，都有模型实测或工艺文件支撑。
3. **最缺功能数据**：除湿量、净化效果、续航、噪音、重量、价格都还没有。这些不补齐，PPT 只能讲成"一件好看的东西"。第 5 节列了要补哪些数据、怎么拿到。
4. **建议主线**：用"柜子里的空气"讲为什么需要 R26，用"雾银、玫瑰金、一圈暖光"让人记住它。

## 1. 现有产品发布在讲什么

### 1.1 六个参考

**Apple HomePod mini（2020）**

- **开场**：先说体积小，再说声音不小。
- **重点**：
  - 尺寸：高 3.3 英寸；
  - 内部部件每个用一句话说明作用：芯片、全频单元、声学波导；
  - 外观：无缝网罩，顶部是会发光的触控面。
- **证据**：精确尺寸和部件名称；颜色作为一个系列发布。
- **R26 可以借的**：
  - 第一页就报尺寸；
  - 结构页每个部件只写一句作用；
  - 灯圈当成"会发光的一圈"来讲，不叫"氛围灯"。

**Dyson 净化器**

- **开场**：先讲看不见的问题，比如过滤器之外的漏风、甲醛。
- **重点**：
  - 整机密封；
  - 催化滤网把甲醛分解成水和二氧化碳，不用更换。
- **证据**：
  - HEPA H13 等级；
  - 原理图；
  - 创始人做第一台吸尘器用了 5127 台样机。
- **R26 可以借的**：用原理图讲二氧化锰在做什么，用迭代次数讲开发过程。

**米家除湿机**

- **开场**：直接给参数。
- **重点**：
  - 日除湿量；
  - 适用面积；
  - 睡眠噪音；
  - 耗电，比如"整晚只需 1 度电"。
- **证据**：数字放大成主视觉，和旧款或同类产品对比。
- **R26 可以借的**：
  - 关键数字单独占一页，字号放大；
  - 把续航换算成生活里的说法，比如"充一次用几天"。

**BALMUDA**

- **开场**：讲一个使用瞬间，不讲参数。
- **重点**：
  - 从"吐司什么时候看起来最好吃"出发；
  - 电器不必当主角，要能融进家里。
- **证据**：讲开发过程。螺旋桨做过 100 个样件，一款产品最多渲染 2000 张图。
- **R26 可以借的**：R26 的暖光和材质适合这样讲。讲"夜里床头那一圈光"，不讲"氛围灯"。

**Levoit Core Mini-P（小型净化器）**

- **开场**：小尺寸，放卧室。
- **重点**：
  - 夜灯；
  - 香薰片；
  - 一个按键切换三档；
  - 最低 25 dB。
- **证据**：噪音、适用面积、CADR。
- **R26 可以借的**：它的形态和 R26 最接近。一个按键、夜灯、低噪音，都是这类用户关心的点。

**衣柜、鞋柜用的小除湿器**（Solenco、Breville、获红点奖的 Mofresh Mini）

- **开场**：先列场景：衣柜、鞋柜、抽屉、行李箱、车。
- **重点**：
  - 不插电；
  - 充电再生，可以循环使用；
  - 颜色窗口提示吸满。
- **证据**：再生时间、使用周期。
- **R26 可以借的**：场景页按"柜子"来讲；告诉用户什么时候该处理，比如倒抽屉、看指示灯。

### 1.2 共同的骨架

1. **一句话**：它是什么，给谁用。
2. **问题**：用户现在遇到的麻烦。最好有一个自己测出来的数字。
3. **揭幕**：产品大图，只配名字。
4. **尺寸和外观**。
5. **结构和原理**：爆炸图，每个部件一句话。
6. **证据**：测试数据、标准、样机过程。
7. **场景**：放在哪、什么时候用。
8. **收尾**：规格、价格、上市时间。

### 1.3 值得照着做的细节

- **一页只讲一件事。** 2007 年 iPhone 发布会常被拿来举例，很多页上只有一两个词。
- **字要大。** 小米内部要求商务材料尽量用大字，雷军也公开说过"小字是行业陋习"。
- **文案讲大白话。** 小米对产品文案有两条要求：
  1. 直接，一听就懂；
  2. 切中要害，用户能感觉到。
- **噪音写标准档，不要只写最低档。** 有评测专门提醒过：只写最低噪音，读者会觉得你在回避。
- **原理讲清楚就够了。** 效果数字只能用自己产品的检测数据。

## 2. R26 手里有什么

### 2.1 已经确定、可以直接用的

出处：《CMF渲染参数报告_v2》《CMF规格书_厂家对接版_v2》。

**尺寸**

- **依据**：Ø74.7 × H155.0 mm，竖向圆柱（模型实测）。
- **可以怎么说**：直径 7.5 厘米，高 15.5 厘米，一只手拿得住。

**结构（从上到下）**

- **依据**：玫瑰金出风格栅 → 雾银上盖 → 暖光灯圈 → 雾银孔阵前壳 → 抽屉 → 玫瑰金底圈。
- **可以怎么说**：用在结构页，分成六段讲。

**进风孔**

- **依据**：前壳和抽屉上约 1056 个 Ø2.05 mm 的孔。
- **可以怎么说**：正面大约 1000 个直径 2 毫米的孔。

**雾银**（外观面积约 81%）

- **依据**：
  - 材料：PC/ABS；
  - 涂层：细银粉漆 + 哑光面漆；
  - 模具外观面：VDI 24–30 火花纹或细喷砂；
  - 视觉颗粒：0.05–0.15 mm。
- **可以怎么说**：摸上去是细砂，不是光面塑料。

**玫瑰金**（外观面积约 17%）

- **依据**：
  - 材料：6063 或 6061 铝；
  - 工艺：机加 → 抛光 → 阳极氧化 → 染色 → 封孔；
  - 膜厚：≥ 10 µm；
  - 顶部旋叶格栅：Ø73.3 × 6 mm；
  - 顶、底两件同牌号、同批阳极。
- **可以怎么说**：顶上和底下两圈是铝，同一批做颜色，所以上下一样。

**灯圈**（外观面积约 2%）

- **依据**：
  - 88 颗 LED；
  - 磨砂扩散罩；
  - 色温 2700K。
- **可以怎么说**：2700K，和白炽灯泡差不多的颜色。

**按键**

- **依据**：正面一个，石墨深灰。
- **可以怎么说**：一个按键。

**接口**

- **依据**：Type-C，位于右后 45°，正面看不到。
- **可以怎么说**：充电口在背面。

**内部**

- **依据**：风扇、二氧化锰模块、活性炭板、电池、主板。
- **可以怎么说**：在爆炸图上标注。

**开发过程**

- **依据**：
  - 文件命名里能看到 R22、R25、R26 几代；
  - 零件有 V2 到 V5 多个版本；
  - CMF 做过 v1 → v2。
- **可以怎么说**：用作过程页的素材。

> **注意**：上面的工艺来自 CMF 方案，工厂打样定版后才能对外说。下面两条在规格书里还列为"待确认"，打样通过之前不要写进对外文案：
>
> - 顶部格栅用 CNC 加工；
> - 从外面看不到灯珠颗粒。
>
> 另外，CMF 报告第 7 章写明：v1 的产品图和三视图还是旧 CMF，不能对外。PPT 和海报一律用 v2 的 .bip 重新出图。

## 3. PPT 方案

### 3.1 定主线

有两条线可以选：

**A 线：柜子里的空气**

- **一句话**：柜子里的空气，也该有人管。
- **参考**：Dyson、米家。
- **需要的素材**：功能数据、自测数据、场景图。
- **风险**：没有数据，就讲不下去。

**B 线：一件好看的电器**

- **一句话**：放在外面也好看的电器。
- **参考**：BALMUDA、Apple。
- **需要的素材**：材质特写、灯光、开发过程。
- **风险**：只讲好看，讲不清为什么要买。

**建议**：整体结构走 A 线，材质那三页用 B 线的讲法。

两条线之间有一个矛盾：放进柜子里，雾银和玫瑰金就没人看得见了。R26 自带电池、一只手拿得住，可以用它把两条线接起来：白天放在衣柜里，晚上拿到床头当夜灯。这个讲法的前提是续航撑得住，要等续航数据出来再定。

### 3.2 逐页方案（20 页，约 15 分钟）

每页列出：

- **画面**：放什么图；
- **文字**：页面上的字；
- **讲**：口头怎么说；
- **素材**：图从哪来。

#### 第一部分：开场（P1）

**P1 封面**

- **画面**：Studio 02 正面主图，白底，产品占画面高度约 60%。
- **文字**：
  - R26；
  - 一句话（从 3.3 节选）。
- **讲**：不说话，停 3 秒。

#### 第二部分：为什么做（P2–P3）

**P2 关上柜门以后**

- **画面**：衣柜内部实拍，画面偏暗，挂着衣服。
- **文字**：
  - 主标题：关上柜门以后
  - 副文案：不通风，潮，有味道。
  - 数字：【待填：自测数据】，例如"柜内湿度比房间高 X 个百分点（N 个衣柜，连续 7 天）"。
- **讲**："我们在 N 个家庭的衣柜里放了温湿度计……"
- **素材**：温湿度计几十元一个，测一周就有自己的数字，比引用网上的数据可信。

**P3 现在的办法**

- **画面**：三栏，每栏一个线框图标。
- **文字**：每栏一句。
  - 除湿机：放不进柜子。
  - 一次性干燥剂盒：吸满就得换。
  - 活性炭包：只能吸附，吸满就不吸了。
- **讲**：只讲品类，不点品牌。原因见 6.3 节的《广告法》第十三条。PPT 会被截图转发，内部版也按对外的标准来做。

#### 第三部分：它是什么（P4–P6）

**P4 揭幕**

- **画面**：深色底，产品居中，灯圈点亮。
- **文字**：R26 紧凑净化除湿器
- **讲**：只说一句话定义。
- **素材**：需要新建一个 Studio。复制 Studio 02，把背景改成深灰。

**P5 尺寸**

- **画面**：二选一：
  - 手握实拍；
  - 产品和一罐 330 ml 易拉罐并排，白底。
- **文字**：
  - 主标题：Ø74.7 × 155 mm
  - 副文案：一只手拿得住。
- **讲**："直径 7.5 厘米，高 15.5 厘米。比一罐 330 ml 的可乐粗一点，高 4 厘米左右。"
- **素材**：这页用打样机实拍，比渲染图可信。

**P6 从上到下**

- **画面**：Studio 02 正面图居中，左右各 3 条引线。
- **文字**：六段名称，每段 2–6 个字：
  - 出风格栅（铝）
  - 上盖
  - 暖光灯圈
  - 进风孔
  - 抽屉
  - 底圈（铝）
- **讲**：顺着引线从上往下念一遍，说明后面会逐段展开。
- **素材**：用 CMF 标注图改，去掉工艺编号，只留名称。

#### 第四部分：怎么做到的（P7–P10）

**P7 爆炸图**

- **画面**：Studio 06 爆炸图（任务书已写好），加上风路箭头。
- **文字**：每个部件一行，写它的作用。
- **讲**：从进风讲到出风，讲一遍空气的路线。
- **【待确认】**：风路方向，以结构设计为准。

**P8 净化**

- **画面**：活性炭板和二氧化锰模块的特写；或者一张简单的原理图：甲醛 → 模块 → 水和二氧化碳。
- **文字**：
  - 主标题：【待定】，例如"甲醛，在这里分解"。
  - 副文案：活性炭吸附异味，二氧化锰在常温下把甲醛分解掉。不需要光照，关着柜门也在工作。
  - 数字：【待填：第三方检测结果和测试条件】
- **讲**：
  - 光触媒要有光才起作用，衣柜里是暗的；
  - 锰氧化物在室温下就能催化氧化甲醛，有文献支持；
  - 这是 R26 适合放在柜子里的一个实在的理由。
- **前提**：先确认二氧化锰模块的设计用途就是分解甲醛。

**P9 除湿**

- **画面**：抽屉拉出来的状态，加一张原理图。
- **文字**：主标题【待填：除湿量，写清测试条件】
- **讲**：按 R26 的除湿原理选一种讲法。
  - **吸湿材料 + 加热再生**：讲一个循环：吸满 → 充电再生 → 接着用。再说清楚怎么知道它吸满了。
  - **半导体冷凝**：讲三件事：水从哪来、存在哪、多久倒一次。

**P10 续航与充电**

- **画面**：产品背面的 Type-C 口特写，旁边配一根线。
- **文字**：
  - 主标题：【待填：续航】
  - 副文案：Type-C 充电。工作时不用插线，放进柜子不用找插座。
- **讲**：把续航换成生活里的说法，比如"一周充一次"。米家用"整晚 1 度电"讲耗电，是同一个思路。

#### 第五部分：材质与灯（P11–P15）

**P11 三种材质**

- **画面**：上方放产品图，下方一根横向比例条：
  - 雾银 81%
  - 玫瑰金 17%
  - 暖光 2%
- **文字**：主标题：雾银、玫瑰金、一圈暖光
- **讲**：大面积用中性的雾银，两头用铝，中间一圈光。暖色只出现在顶部、底部、腰线三个地方，所以整机看上去不发黄。

**P12 雾银**

- **画面**：机身微距。用低角度掠射光，让细砂颗粒显出来。
- **文字**：
  - 主标题：细砂，颗粒约 0.1 毫米
  - 副文案：模具表面做火花纹，再喷细银粉漆和哑光面漆。摸上去是细砂，不是光面塑料。
- **素材**：裁 Studio 05，或者单独渲染一张微距。

**P13 玫瑰金铝**

- **画面**：Studio 04 高俯角，拍顶部格栅。
- **文字**：
  - 主标题：顶上这一圈，是铝。
  - 副文案：6063 铝，阳极氧化染成玫瑰金。顶部格栅和底圈同一批做颜色，上下一致。
- **注意**：格栅用 CNC 还是冲压、怎么抛光，等铝件厂定方案后再写。

**P14 一圈暖光**

- **画面**：同一机位并排两张：
  - 左：关灯，一圈乳白；
  - 右：开灯，暖光。
- **文字**：
  - 主标题：2700K
  - 副文案：和白炽灯泡差不多的颜色。88 颗灯珠，藏在磨砂罩后面。
- **讲**：讲一个瞬间：夜里起床，床头有一圈暖光，不用开大灯。
- **【待填】**：亮度有几档；能不能只开灯、不开风扇。
- **注意**："看不到灯珠颗粒"这句话，等扩散罩打样确认后再说。

**P15 细节**

- **画面**：三张特写横排：按键、背面充电口、孔内壁。
- **文字**：
  - 一个按键。【待填：操作逻辑，例如"短按换档，长按开灯"】
  - 充电口在背面，正面看不到。
  - 孔里面也是雾银。
- **讲**：v1 的孔里面是深灰色，v2 全改成了雾银。侧着看进去，孔壁和外面是同一种颜色。这种细节讲一个就够，讲多了像在凑数。

#### 第六部分：开发过程（P16）

**P16 从 R22 到 R26**

- **画面**：历代样机或渲染图排成一排。
- **文字**：
  - 主标题：【待填：做了几版】
  - 副文案：【待填：每版改了什么】，例如"R25 加了活性炭板；R26 把顶和底换成了铝"。
- **讲**：Dyson 讲 5127 台样机，BALMUDA 讲 100 个螺旋桨样件。数字要真，小一点没关系。

#### 第七部分：用在哪（P17–P18）

**P17 四个地方**

- **画面**：2 × 2 场景图：衣柜、鞋柜、床头、书桌。
- **文字**：每格一句。
  - **衣柜**：关着门也在工作。
  - **鞋柜**：【待填：除味效果】
  - **床头**：一圈暖光，当夜灯。
  - **书桌**：【待填：标准档噪音】
- **注意**：车内杯架要先实测。Ø74.7 mm 不一定放得进所有杯架。

**P18 一天（可选）**

- **画面**：两张：
  - 早上，放回衣柜；
  - 晚上，拿到床头。
- **前提**：续航撑得住才放这一页。

**P19 规格**

| 项目 | 内容 |
|---|---|
| 尺寸 | Ø74.7 × 155 mm |

## 6. 文案写法

### 6.1 五条规则

1. 有数字就写数字，有材料名就写材料名。
2. 一句只说一件事，句子要短。
3. 写用户看得见、摸得着、听得到的东西。
4. 写完把形容词删掉。删了以后意思不变，就删。
5. 不用这些词：
   - 极致、颠覆、重新定义、赋能、匠心、黑科技、沉浸式、全方位、打造、高端大气、科技感满满；
   - "开启……新篇章"；
   - "不仅……更是……"。

### 6.2 改写对照

| 不要这样写 | 改成 |
|---|---|
| 匠心工艺，极致质感 | 顶上这一圈，是铝。 |
| 温馨氛围灯，营造浪漫氛围 | 2700K，和白炽灯泡差不多的颜色。夜里起来不用开大灯。 |
| 小巧便携，随心放置 | 直径 7.5 厘米，一只手拿得住。工作时不用插线。 |
| 高效净化，守护家人健康 | 二氧化锰在常温下分解甲醛，不需要光照。（去除率以检测报告为准） |
| 高级质感，低调奢华 | 摸上去是细砂，不是光面塑料。 |
| 静音设计，安心好眠 | 睡眠档【X】dB。 |
| 细节之处见真章 | 孔里面也喷成了雾银。 |

### 6.3 合规

- **《广告法》第九条**：不用"最""第一""顶级""国家级"这类绝对化用语。
- **《广告法》第十一条**：引用的数据必须真实、准确，并注明出处；有适用范围的，要写明范围。所以除湿量、去除率、噪音旁边，都要配一行小字写测试条件。
- **《广告法》第十三条**：不能贬低其他商品。对比时只讲品类，不点品牌。
- **认证类说法**：没有对应认证，就不写"母婴级""医用级"。
- **渲染图**：对外使用时加一句"图片仅供参考，以实物为准"。CMF 报告里"颜色以签字色板为准"的说明同样适用。
