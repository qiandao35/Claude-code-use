# KeyShot 结构爆炸图渲染任务书（R26 · CMF v2）

> **使用方式**：把本文整份发给执行渲染的 AI（需要能在用户电脑上操作 KeyShot 2024.2 Pro，可以用 GUI，也可以用 KeyShot 脚本接口），同时附上第 1 章列出的文件。

---

## 0. 角色与目标

你是资深产品渲染师。产品是紧凑净化除湿器 R26，整机 CMF 已经定稿（以《CMF渲染参数报告_v2》为准）。

本次任务只有一件事：**把用户提供的结构爆炸图模型渲染成白底爆炸图**。要求如下：

1. **外观件的 CMF 与主视图完整产品完全一致**。必须直接使用 .bip 中现成的材质，不得新建近似材质替代。
2. **内部结构 / 支撑件一律使用雾银外壳材质**（CMF01，同一参数，链接同一个材质）。
3. **风扇、二氧化锰模块、电池、主板**用第 5.3 节规定的简化材质。
4. **交付** 1 张白底爆炸图，以及一份能用 KeyShot 打开的打包文件（.ksp）。

## 2. 硬性规则（全程有效，违反即返工）

1. **不改几何、不改爆炸摆位。**零件位置、间距、角度一律以文件 A 为准。唯一允许的模型操作，是第 3 章阶段 3 中把底盖拆分成几个独立物件，且不改变任何形状。
2. **CMF 只能来自本任务书。**
   - 外观件和支撑件：从文件 B 的项目材质中直接赋予（链接同一材质），不得复制成副本后改参数，不得新建“看起来差不多”的材质。
   - 简化件：严格按第 5.3 节的参数新建，不得自行发挥。
3. **灯圈保持点亮态**，与主视图一致：CMF03 用“点亮态”，CMF04 用“灯亮”。
4. **纯白背景**。不加道具、文字、标注线、地面纹理、Logo。
5. **不做后期调色**。只允许把带 Alpha 的母版合成到纯白（RGB 255, 255, 255）上，不调曲线、饱和度、白平衡。
6. **原有 Studio 01–05 不得被改变**。所有新内容放进新的模型集、新相机和新 Studio。
7. **无法归类的零件，停下来问用户**。不确定的地方不猜。

## 3. 执行流程

### 阶段 1：建立工作文件

**1.1 另存工作文件**

打开文件 B，先“文件 → 另存为”`R26_爆炸图_CMF_v1.bip`。原文件 B 不动。

**1.2 导入文件 A**

“文件 → 导入”文件 A（如需拆分底盖，按阶段 3 处理后再导入），导入设置：

- 几何体：**添加到场景**，不要选“更新几何体”；
- 单位 mm；保留零件结构，不合并；
- 不居中、不贴地，保持原始坐标；上方向按 Rhino 的 Z 向上；
- 镶嵌精度与原场景一致（v1 记录为：导入镶嵌精度 1.0 + 精确镶嵌）。

**1.3 新建模型集 `MS_爆炸图`**

- 这个模型集里只显示新导入的爆炸图模型；
- 原装配模型（Default 中的产品）、`MS_台面`、`MS_道具`、`MS_材质对照_原参数` 在这个模型集里全部隐藏；
- 确认 Studio 01–05 仍然绑定各自原来的模型集，没有受到影响。

### 阶段 2：零件分类映射（检查点 1）

逐个识别文件 A 中的零件，按第 4 章分为 A / B / C / D 四类，填写映射表：

| 零件名（场景树） | 识别依据（名称 / 形状 / 位置） | 类别 | 赋予材质 | 备注 |
|---|---|---|---|---|

- 参考零件名见第 4 章。文件 A 的命名可能和旧场景不同，要以实际名称和形状为准。
- 归入 D 类的零件，要列出零件名并附截图。

> ✅ **检查点 1**：把映射表发给用户确认后，再进入阶段 3。如果用户事先说明“无需确认”，可以跳过。

### 阶段 3：底盖分面（只针对底盖 652）

底盖 `V2_BOTTOM_COVER_REINFORCED`（652）一个零件上有三种 CMF，需要拆成三个独立物件：

| 区域 | 范围 | 材质 |
|---|---|---|
| 外圈 | 底盖外圆柱面中，从底盖自身最低点起 0–6.5 mm 高度段 | CMF02 玫瑰金 |
| 底面 | 朝下的外表面与沉孔 | G1 石墨深灰 |
| 其余 | 内腔、立柱、内壁、顶面 | CMF01 雾银（本次新规则：内部支撑结构用雾银） |

拆分要求：

- 推荐在文件 A 的副本中用 Rhino `ExtractSrf`（抽离曲面）或 `Split`（分割）处理后再导入。也可以用脚本按面拆分。
- 不改变任何曲面形状和位置。
- 如果文件 A 中外圈已经是独立物件，就跳过外圈这一步。

### 阶段 4：赋材质

1. **按映射表逐类赋予**：
   - A 类、B 类：从项目材质中直接拖放或脚本赋予，链接到同一个材质；
   - C 类：先按 5.3 新建 X1–X6 材质，再赋予。
2. **核对数量**：赋完后按“材质 → 使用的零件数”列表核对。导入时残留的默认材质（Rhino 默认材质、名称为 Default 或 Material 的材质）数量必须为 0。
3. **不得改动 .bip 中 CMF01 / CMF02 / CMF03 / CMF04 / G1 / K1 的任何参数**。

### 阶段 5：环境与灯光

**5.1 新建环境 `CMF_Explode`**

完全复制 `CMF_Neutral` 的设置：

- HDRI：startup.hdr，亮度 1.0，旋转 0°，环境尺寸 3 m；
- 背景纯白 RGB 255, 255, 255；
- 地面阴影开，地面遮挡阴影开，地面反射关。

唯一允许的调整：悬空零件的投影在地面上显得杂乱时，可以关闭“地面遮挡阴影”，并在交付时记录。

**5.2 补光面板**

1. 在 `MS_爆炸图` 中复制一套隐藏补光面板，命名 `LGT_*_EXP`。材质、强度与原面板相同，参数见附录 C。
2. 以爆炸图包围盒中心为新中心，按比例 k = 爆炸图包围盒高度 ÷ 155 mm，同比放大各面板的距离和尺寸（k 限定在 1.0–2.5 之间）。
3. 方位角、仰角、强度保持不变。
4. 原 `LGT_*` 面板不得移动，以保证 Studio 01–05 不变。

### 阶段 6：相机与 Studio

**6.1 新建相机 `CAM06_爆炸图`**

- 视角复刻参考图 D①：从前方偏左上方俯视，俯角以截图为准，约 25–35°；
- 焦距 50–85 mm（从 70 mm 起调），避免透视变形；
- 全部零件入画，四周留白不少于 8%，构图居中。

**6.2 新建 `Studio 06 爆炸图`**

| 项目 | 设置 |
|---|---|
| 模型集 | `MS_爆炸图` |
| 相机 | `CAM06_爆炸图` |
| 环境 | `CMF_Explode` |
| 图像样式 | 与 Studio 02 相同（Basic / Default） |
| 多材质 | CMF03 = 点亮态，CMF04 = 灯亮 |

### 阶段 7：预览自检（检查点 2）

1. 先用同一文件渲染一张 Studio 02 低分辨率预览（主视图，不交付），作为颜色基准。
2. 再渲染 Studio 06 预览（800 × 800），与基准逐项比对：

| # | 检查项 | 标准 |
|---|---|---|
| 1 | 雾银 | 外观件与支撑件颜色、细砂颗粒、光泽和主视图一致：中性略偏冷，不偏蓝、不偏黄 |
| 2 | 玫瑰金 | 格栅、底盖外圈为高光香槟粉金，有清晰的金属反射，不偏橙铜色 |
| 3 | 灯圈 | 点亮，暖黄均匀，与主视图一致 |
| 4 | 简化件 | 颜色符合 5.3，不抢外观件的视觉 |
| 5 | 背景与零件 | 背景纯白；没有残留默认材质；没有漏赋材质的零件 |
| 6 | 摆位 | 与文件 A 一致，没有被移动 |

> ✅ **检查点 2**：把两张预览并排发给用户确认，再出终稿。

### 阶段 8：出图与打包

**8.1 渲染设置**（与主视图终稿一致）

| 项目 | 设置 |
|---|---|
| 渲染引擎 | CPU 产品模式 |
| 采样 | 256；小零件噪点明显时提高到 384，不开降噪 |
| 光线反弹 / 全局照明 / 焦散 | 14 / 开 / 关 |
| 降噪 | 关 |
| 输出 | 3000 × 3000 PNG，带 Alpha 母版；白底版 = 母版合成到 RGB 255, 255, 255，只合成，不调色 |

**8.2 保存与打包**

1. 先保存 .bip，再“文件 → 打包保存”生成 .ksp（包含模型、材质、HDRI、全部 Studio）。
2. 把 .ksp 复制到另一个路径重新打开，确认以下内容都完整：
   - Studio 01–06 共 6 个；
   - 模型集 `MS_爆炸图`；
   - 全部材质。
3. 注明打开这个文件需要 KeyShot Studio 2024.2 Pro 或更高版本。
