## 1. 修正操作（按顺序执行）

### 1.1 另存

"文件 → 另存为" `R26_CMF_A_旗舰质感版_v1.1.bip`。第 1 轮的文件保留不动。

### 1.2 金属顶（问题 1）

**原因**：喷砂金属看起来有多亮，取决于它反射到了什么。从正面俯视时，格栅顶面反射的是产品**后上方**的方向。原来的 `LGT_TOP` 在产品前上方，照不进这个方向，所以格栅只反射出灰色的环境。

1. **新建后上方反射板 `LGT_BACKTOP`**：

   | 项目 | 值 |
   |---|---|
   | 位置 | 方位角 90°（产品正后方，+Y）/ 仰角 40° / 距产品中心 650 mm，世界坐标中心约 (0, 498, 495) mm；面板朝向产品中心 (0, 0, 77.5) |
   | 尺寸 | 1000（水平）× 800 mm |
   | 材质 | 白色 Emissive，和其他 `LGT_*` 面板相同：对相机不可见，反射中可见，不投阴影 |
   | 强度 | 3.0（允许 1.5–6） |
   | 模型集 | 放在 Default 中；在 `MS_橱柜情境` 中隐藏 |

2. **修改 A04_M_浅香槟银_喷砂铝**：color (0.886, 0.859, 0.812)（226, 219, 207）；roughness 0.24（允许 0.20–0.30）；glossy samples 16。
3. **校准**：渲染 Studio 04 预览（灯灭），在 1.5–6 范围内调 `LGT_BACKTOP` 强度，直到格栅中心圆盘亮度达到 180–215，同时槽缝亮度不超过叶片亮度的 60%。

### 1.3 灯光状态（问题 2）

1. **核对子材质的颜色数值**：
   - A09、A10 的 `4000K` 子材质 = (1.0, 0.820, 0.639)；
   - `琥珀` 子材质 = (1.0, 0.588, 0.157)。

   第 1 轮主图的灯带色落在琥珀的数值范围内。如果你当时选的是 4000K，说明子材质的颜色设错了。
2. **各 Studio 的状态（不得改动）**：

   | Studio | 01 | 02 | 03 | 04 | 05 | 06 | 07a | 07b | 07c | 08a | 08c |
   |---|---|---|---|---|---|---|---|---|---|---|---|
   | 状态 | 灯灭 | 4000K | 4000K | 灯灭 | 4000K | 4000K | 4000K | 琥珀 | 灯灭 | 灯灭 | 琥珀 |

3. **新建 Studio 07c 橱柜情境·灯灭**：设置和 07a 相同，只把状态改为灯灭。灯光状态三联图由 07c、07a、07b 组成。
4. 白底图里，4000K 灯带看起来接近一条白线，这是正常的。**不要**为了"看得出在亮"去改颜色或加辉光。

### 1.4 环境与瓷白（问题 3、5）

1. Studio 02、03、04、05、08 只用附录 B 规定的环境：startup.hdr，加纯色背景 RGB 255。删除或隐藏弧形影棚墙等背景几何，不得使用其他 HDRI。
2. `CMF_Main_S02` **关闭地面反射**。
3. 检查原始渲染（合成之前）的背景区域：|R−B| ≤ 3。
4. 环境改为中性后，渲染 08a 预览，测机身正面中部：
   - **R < 205**：先把 CMF_Neutral、CMF_Main_S02 的亮度在 0.85–1.20 内上调；调到 1.20 仍然不够，再把 LGT_KEY 在 4–5.5 内上调；
   - **R−B < 8**：把 A01、A02、A03 的 base_color 同时改为 (0.925, 0.902, 0.855)（236, 230, 218）。
5. 机身上纯 255 的区域不得超过产品面积的 2%。

### 1.5 按键（问题 4）

把 `A07_G_鼠尾草绿_按键` 赋给 `V2_SOURCE_BUTTON_WITH_SHORT_STEM`，包括按键帽和下面的小柱。
如果灯带正中那个小方块不是这个零件，截图告诉用户它是哪个零件，不要自行赋色。

### 1.6 爆炸图（问题 6）

1. 格栅赋 A04；顶环支架 `V3_FAN_TOP_RING_CROSSBAR_TWO_HOLES` 赋 A05；按键赋 A07。
2. 白件全部链接主场景的 A01 / A03。删除爆炸图里另外复制或新建的白色材质。颗粒感必须和主图一致。
3. 新建 `LGT_BACKTOP_EXP`：按旧爆炸图任务书阶段 5.2 的方法，以爆炸图包围盒中心为新中心，按比例 k 放大距离和尺寸。
4. 采样 384。背景用 CMF_Explode（白）；如果用户要灰底，就把 Alpha 母版合成到 RGB 236, 234, 230，和产品的暖灰底版保持统一。

### 1.7 补齐图片（问题 8）

按 v1.1 的 Studio 清单补齐：三视图（01）、橱柜情境 07a / 07b / 07c、白底 08a / 08c，以及全部合成版本（白底、暖灰底、三视图 A3 拼版、橱柜三联图）。
