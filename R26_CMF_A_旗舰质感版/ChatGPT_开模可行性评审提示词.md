# R26 开模可行性（DFM）评审 · ChatGPT 提示词

## 使用说明（给你自己看，不用发给 ChatGPT）

### 先准备文件

一起发给 ChatGPT 的文件越容易解析，它能"实测"的东西就越多，靠猜的就越少。

| 文件 | 怎么导出 | 用途 |
|---|---|---|
| ① 原始 .3dm | 直接发 | 看结构、零件名、图层 |
| ② **每个零件一个二进制 STL**（单位 mm，精细网格） | Rhino 中选中单个零件 → 导出所选物件 → STL，选"二进制"，网格设细一些（最大边长约 0.3 mm 以内） | **最重要。**ChatGPT 可以用 Python 直接读二进制 STL，计算体积、包围盒、拔模角分布、壁厚，结果是真实算出来的 |
| ③ 每个零件一个 STEP（AP214），加一份总装 STEP | 导出所选物件 → STEP | 工厂开模用的正式数据。ChatGPT 不一定能解析，但要让它检查命名和数量 |
| ④ 《CMF渲染参数报告_v3_旗舰质感版.pdf》 | 仓库里已有 | 材料、纹理、A/B/C 面的依据 |

文件太多一次传不完时，先传 ② 和 ④，最后再传 ①。

### 怎么提问

- **分轮发**：先发第 0 段"总设定"，再按第 1–6 轮依次发。不要一次全发，ChatGPT 一次处理太多零件会变得笼统。
- 每一轮结束后，看它是否标注了"实测 / 估算 / 经验 / 需工厂确认"。没标注的，追问一句："这个结论是从文件里算出来的，还是经验判断？"
- 它说"算出来"的数字，要求它把代码和中间结果给你看。

### 要有正确的预期

- ChatGPT **不能代替**模具厂的 DFM 报告和 Moldflow 模流分析。它能做的是：检查数据质量、按设计规范做初筛、用公式做粗略估算、帮你列出问工厂的问题清单。
- 正式开模前，一定要请模具厂出 **DFM 报告**（多数模具厂报价阶段就会免费提供），白色免喷涂件、多孔件最好再做一次**模流分析**。
- ChatGPT 提出的修改，如果会改变外观（拔模、圆角、分型线位置），要你自己判断是否接受，不要让它直接改模型。

## 第 1 轮：模型数据质量（能不能直接交给工厂）

```
第 1 轮：检查模型数据质量。这一轮只看"数据能不能直接交给模具厂"，先不评审结构。

请逐项检查并给出表格（零件 × 检查项，结果填 通过 / 不通过 / 读不到）：
1. 单位是否为 mm；零件数量和命名是否与清单一致，有没有多余、重复或未命名的对象。
2. 每个零件是否是**封闭实体**（Rhino 中的 Closed Polysurface）：有没有外露边（naked edges）、非流形边、破面、重叠面、极小碎面。
3. 有没有**网格物体**混在 NURBS 实体里（例如风扇 SRC_578_Fan 曾报 invalid mesh）。模具厂需要的是实体，不是网格。
4. 建模公差：Rhino 绝对公差是多少；是否适合模具（通常 0.001–0.01 mm）。
5. 零件之间有没有**干涉**（实体互相穿插）；有没有本该接触却留了缝、或者间隙为 0 的配合面。
6. 圆角、曲面连续性有没有明显问题（会造成咬花不均或抛光困难的折痕）。
7. 是否每个零件都可以单独导出为 STEP 实体。

如果你能解析我给的 STL：请用 Python 计算每个零件的体积、表面积、包围盒尺寸、是否水密（watertight），以及网格中是否有自相交或破洞，并列出结果。

对于你读不到的项目，请写出我在 Rhino 中要执行的具体操作（例如对零件执行 Check、SelBadObjects、ShowEdges 查看外露边、用 Intersect 或布尔交集检查干涉），以及我要把什么结果发给你。

最后给出结论：数据质量是否达到交付标准，以及必须先修的 A 级问题清单。
```

## 第 2 轮：重点零件 DFM（孔阵件：前壳 644、抽屉 648）

```
第 2 轮：对前壳 644 和抽屉 648 做详细 DFM。这两件是整套模具里最复杂、最贵、风险最大的零件（圆柱曲面 + 约 1,056 个径向孔 + 咬花 + 白色免喷涂）。

请逐项分析：

【A. 开模方向与滑块方案】
1. 判断这两件最合理的开模方向和分型方案：主开模方向是哪个方向？圆柱外表面和孔阵需要几个滑块？每个滑块的运动方向是什么？
2. **重点检查孔的轴线方向**：滑块上的型芯针只能做出与滑块运动方向平行的孔。如果孔是严格的径向孔，离滑块中心方向越远，孔轴线与滑块方向的夹角越大，就会形成倒扣、无法脱模。请：
   - 如果能读取几何：【实测】每个孔的轴线方向与你建议的各滑块方向之间的夹角，统计分布，标出超过可接受角度的孔（说明你采用的允许角度及依据）；
   - 给出可行的解决办法，例如增加滑块数量、把每个区域的孔改为与该滑块方向平行、调整孔阵边界避开滑块分界线，并说明每种办法对外观的影响。
3. 滑块分界线（夹线）会在白色咬花外表面上留下痕迹。请判断分界线落在哪里，是否会穿过孔阵、是否明显，有没有办法藏到不显眼的位置。

【B. 拔模】
4. 外观面咬花 VDI 27：按 PC/ABS 和 VDI 27 的经验，需要的拔模角是多少（说明依据，最终以咬花厂推荐为准）。
5. 检查每个面相对于其脱模方向（主开模或滑块方向）的拔模角。如果能读取 STL，【实测】计算各面法线与脱模方向的夹角，统计拔模角低于要求的面积和位置，并说明计算方法。
6. 孔内壁（光面型芯针）的拔模要求；孔的长度与直径之比是否合理，型芯针强度是否有风险。

【C. 壁厚与结构】
7. 主壁厚是多少；壁厚是否均匀；最厚和最薄处在哪里。如果能读取 STL，【实测】用射线法估算壁厚分布（说明方法和采样数量）。
8. 孔与孔之间的钢料（筋）宽度是否足够；孔离边缘、离分型线、离筋骨的距离是否足够。
9. 筋、螺丝柱、卡扣、抽屉的三个卡位柱（capture posts）：厚度与主壁厚之比、根部圆角、高度，是否会在外观面产生缩痕。
10. 卡扣和倒扣：需要斜顶还是滑块；PC/ABS 卡扣的变形量是否在材料允许应变范围内（说明你采用的允许应变值和依据）；抽屉需要反复抽拉，卡位是否耐疲劳。

【D. 浇口、熔接线、顶出（白色免喷涂件重点）】
11. 建议浇口类型和位置：外观面不能有浇口痕（例如从内侧潜伏进胶、点浇口或热流道阀针进胶），说明理由。
12. 1,056 个孔一定会产生大量熔接线。请预判熔接线和困气的大致位置，以及能否通过浇口位置把明显的熔接线引到不显眼的区域。标注【估算】或【需工厂确认 / 需模流分析】。
13. 顶针、顶块只能放在内表面（B / C 面）。判断顶出是否足够、会不会顶白或变形。

【E. 变形与配合】
14. 薄壁半圆柱 / 圆筒注塑后容易椭圆和翘曲。评估 644、648 的变形风险，以及对抽屉滑动配合和外观段差的影响。
15. 抽屉与机身之间的滑动间隙、拉手槽位置是否合理。

请输出：
- 每一项的结论（标注证据来源）；
- 两个零件的模具方案示意（开模方向、滑块数量和方向、分型线位置的文字描述）；
- A / B / C 级问题清单；
- 一句话结论：这两件目前是"可以开模 / 修改后可以开模 / 不能开模"。
```

## 第 3 轮：其余注塑件 DFM

```
第 3 轮：对其余注塑件做 DFM。请按零件逐个评审，每个零件用同一个格式：

零件：上盖 645、底盖 652（含外圈）、Type-C 盖板 658、风道灯座件 R26_DUCT_MNO2_LIGHTRING_CARRIER、风扇顶环支架、排水板 V5_DRAIN_PLATE、固定导板、扩散罩 LIGHT_DIFFUSER_NOMINAL、按键。

每个零件检查：
1. 开模方向、分型线位置，是否需要滑块或斜顶。
2. 拔模角是否足够（外观咬花面按 VDI 27 的要求，光面按光面要求）。能读取 STL 的就【实测】。
3. 主壁厚、壁厚均匀性、筋和螺丝柱比例、缩痕风险。
4. 浇口和顶出位置建议（外观面不能有痕迹）。
5. 零件特有的风险：
   - 上盖 645：与格栅的配合；顶部的格栅定位缺口在白色外观上很明显，评估能否移到背面或更隐蔽的位置（只给建议，不改模型）。
   - 底盖 652：外圈现在改为与底盖一体注塑，检查外圈与主体的连接、缩痕、与硅胶垫贴合面的平整度。
   - 风道灯座件：外露唇边是外观面，要和外壳同色；靠近 LED 的部位会不会漏光；壁厚是否足以遮光。
   - 排水板：接触冷凝水，排水坡度和排水路径是否合理；与电子仓之间是否有密封结构。
   - 扩散罩（PC）：壁厚均匀性对匀光的影响；浇口位置会不会在发光带上留下痕迹；PC 的流动性和应力。
   - 按键：行程、导向、与灯圈的配合，会不会卡键或晃动。
6. 该零件结论：可以开模 / 修改后可以开模 / 不能开模。

最后给出所有注塑件的汇总表和 A / B / C 级问题清单。

## 第 4 轮：铝格栅 CNC 与阳极氧化

```
第 4 轮：评审顶部格栅 SOURCE_TOP_GRILLE 的可加工性。工艺：6063 或 6061 → CNC → 细喷砂 → 阳极氧化 AA10 → 浅香槟着色 → 封孔 → 中心镭雕 logo。

请检查：
1. 叶片厚度、叶片间缝宽、缝的深度。如果能读取几何就【实测】最小叶片厚度、最小缝宽、最小内角半径。
2. 加工可行性：最小缝宽和内角半径对应需要多小的刀具；缝深与刀径之比是否在合理范围；需要 3 轴还是 5 轴；薄叶片会不会振刀、变形。
3. 毛刺和锐边：哪些边需要倒角或倒圆，才能保证阳极膜覆盖、手感不割手（说明建议尺寸及依据）。
4. 喷砂：缝隙内和叶片背面能不能喷到、喷得均匀。
5. 阳极氧化：挂具点（导电点）放在哪里不影响外观；深缝内膜厚和颜色是否会不均。
6. 与上盖 645 的装配方式（卡、胶、螺丝），以及定位结构。
7. 用【估算】给出单件 CNC 工时的量级和主要影响因素（说明假设），并指出哪些几何改动能明显降低工时而不影响外观。

输出：可加工性结论、A / B / C 级问题清单、需要铝件厂和阳极厂确认的问题。
```

## 第 5 轮：装配、公差与模拟估算

```
第 5 轮：整机装配和公差评审，并做可以做的模拟估算。

【A. 装配与公差】
1. 列出所有零件之间的配合关系（卡扣、螺丝、止口、滑动配合），检查有没有装配顺序问题或装不进去的情况。
2. 外观分缝：上盖 / 灯圈 / 前壳 / 抽屉 / 底盖之间的间隙和段差。【实测】模型里的名义间隙，再【估算】考虑收缩率差异和公差后的实际范围（PC/ABS、ABS、PC 收缩率请说明取值和来源；尺寸公差可参考 GB/T 14486）。外观目标：段差约 0.1–0.15 mm 以内，间隙均匀。
3. 抽屉与机身的滑动配合间隙是否合理，会不会卡或晃。
4. 电子仓与潮湿空气腔之间的密封；Type-C 口、按键、LED 的位置精度。
5. 螺丝柱与螺丝规格是否匹配（自攻螺丝底孔、柱外径），是否标明螺丝规格。

【B. 模拟估算（全部标注【估算】，写清公式和假设）】
6. 每个注塑件的体积和重量（PC/ABS、ABS、PC 的密度请说明取值）；能读取 STL 的用实测体积。
7. 投影面积和锁模力估算，推荐注塑机吨位。
8. 流动长度与壁厚之比（L/t），判断是否有充填不足的风险。
9. 冷却时间和成型周期的量级估算。
10. 收缩后关键配合尺寸的变化（例如抽屉外径与机身内径），判断是否需要预留修模余量（"留钢"）。

【C. 安规与环境】
