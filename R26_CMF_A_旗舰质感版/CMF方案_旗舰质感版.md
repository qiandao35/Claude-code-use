## 1. 设计定位

### 1.1 这个产品要对用户说什么

在橱柜里，这台产品要说的是：**"有我在，这里干爽、干净，你可以放心。"**

v2 的"雾银 + 玫瑰金 + 2700K 暖光"表达的是"精致的轻奢小物"，让人联想到梳妆台、香薰、音箱、保温杯，和厨房橱柜对不上。

### 1.2 设计概念：瓷罐

厨房里最让人信任的器物，是陶瓷储物罐、茶叶罐：瓷白的罐身、金属的盖子，干净、安静，放在柜子里理所当然。

| 瓷罐的元素 | 对应到 R26 |
|---|---|
| 瓷白罐身 | 暖瓷白 PC/ABS 本色注塑，细咬花哑光 |
| 金属罐盖 | 顶部 CNC 涡轮格栅，喷砂加浅香槟阳极 |
| 罐身上的一道线 | 腰线灯圈：关灯时是乳白线，开灯时变成状态光 |
| 罐里装着的东西 | 透过孔阵隐约看到鼠尾草绿的初效滤网，让人感觉"里面是干净的空气" |

## 2. 这套 CMF 的价值

### 2.1 功能价值

| 问题 | 怎么解决 |
|---|---|
| 1,056 个孔的孔内壁喷不到漆 | 外壳改为本色注塑、不喷涂，孔壁和外表面自然同色 |
| 划伤露底色 | 本色件划伤后露出的仍是同色，没有掉漆问题 |
| 水渍、水垢、指纹 | 外壳哑光浅色，格栅喷砂哑光，都不显水渍和指纹 |
| 清洁剂腐蚀 | 不喷涂就没有漆膜失光、起泡的问题；铝件用电解着色，比有机染色耐候；规格书增加耐化学品测试 |
| 油烟、灰尘 | 初效滤网先挡一层，保护主滤材，也可以水洗或更换 |
| 暗处看不清 | 浅色在暗处也看得见；灯光从"氛围光"改为"状态光" |
| 滑动、振动噪声 | 底部硅胶垫防滑；电机加减震圈（橱柜会把振动放大） |
| 潮湿环境的电子可靠性 | 主板和灯板刷三防漆，螺丝用 304 不锈钢 |

### 2.2 情感价值

干净、清新、安心、安静。完整说明见第 3 章的四个情感层。

### 2.3 商业价值

1. **成本更低**：去掉外壳喷涂、格栅抛光和底部铝圈，单台比 v2 低约 25 元。
2. **辨识度**：同类产品多是"白色塑料盒"或"仿金属小家电"。"瓷罐加金属盖"在货架和详情页上一眼就能区分。
3. **低成本扩展款式**：外壳是本色注塑，以后只要换色母（例如燕麦色、雾绿色）就能出新款，模具不用改，金属顶盖可以通用。

## 4. 方法来源：前面的总结和五个案例怎么用上的

| 原则 | 来源 | 在 R26 上怎么用 |
|---|---|---|
| 材料克制 | 五个案例的共同规律 | 主要只有 3 种材料（瓷白塑料、浅香槟铝、乳白扩散罩），主色 1 个 |
| 软硬对比 | 五个案例的共同规律 | 温润的瓷白罐身，配精密的金属顶；脚下是柔软的硅胶 |
| 颜色表达结构 | Nike 口罩（中间层用彩色） | 孔阵后面的绿色滤网，让"过滤层"被看见 |
| 功能结构变成装饰 | Honeywell 净化器（冲孔即装饰） | 涡轮格栅和孔阵本身就是视觉主角，不再加装饰 |
| 同色不同质 | POC 头盔（全黑靠质感分层） | 同一个瓷白，咬花面、光面拉手槽、光面孔壁三种质感 |
| 点缀落在功能点上 | Aperitivo（皮革只在把手） | 绿色只用在按键和滤网这类用户能动手的部件 |
| 材料气质统一，金属当签名 | B&O 音箱（金属上刻品牌） | 瓷白和浅香槟铝都偏温润；logo 镭雕在格栅中心 |
| 主辅点缀比例 | 色彩 60/30/10 经验法则 | 瓷白约 77%、金属约 12%、绿色点阵约 9%、灯光约 2%（见 6.2） |
| 品牌标识低调 | 五个案例的共同规律 | 镭雕在金属上，不做大面积印刷 |

## 5. 橱柜环境的对策

| 橱柜环境 | 对策 |
|---|---|
| 暗，开门只有一面来光 | 浅色主体；状态光；格栅用浅色金属，在暗处也能看清 |
| 以俯视为主（地柜） | 把最好的工艺（CNC 金属）放在顶面，俯视第一眼就是质感最高的部分 |
| 潮湿、滴水、水垢 | 全部外露面哑光，没有高光金属 |
| 清洁剂多 | 不喷涂；电解着色阳极；补充耐化学品测试 |
| 油烟 | 初效滤网可清洗或更换；外壳咬花不宜过粗，避免藏油 |
| 霉菌 | 增加防霉测试；排水板和抽屉内腔用光面，不藏水 |
| 拥挤、常被碰 | 本色件耐刮；底部不用金属（金属最先被刮花） |
| 推拉、振动 | 硅胶底垫防滑；电机减震 |

### 6.1 色板

渲染参考值只用于 KeyShot，量产以签样色板为准。

| 代号 | 名称 | 渲染参考（sRGB） | HEX | 用在哪里 | 意思 |

**为什么金属选"浅香槟银"，而不是纯银或玫瑰金**
- 纯银放在暖瓷白旁边会显冷、发灰；在暗柜里更像灰塑料。
- 玫瑰金带有个护、美妆的联想。
- 浅香槟银饱和度很低，接近本色铝，只偏暖 3–5%，和高端厨房五金同一个语言。
- 验收标准：不能看起来像金色，也不能偏粉。

## 8. 工艺规格与检测

以下标准号沿用《CMF清单_厂家对接版_V1.xlsx》「测试要求」表中 2026-10-09 检索的版本；签合同前请到全国标准信息公共服务平台复核。标准大多只规定方法，判定值要和工厂约定后写进技术协议。

### CMF-A1 · W1 暖瓷白外壳（本色注塑）

| 项目 | 内容 |
|---|---|
| 材料 | PC/ABS，W1 色母；原料要洁净（白色本色件最怕黑点）；料筒专机或彻底清洗 |
| 表面 | 外观面 VDI 27 起步（24 / 27 / 30 三档打样）；孔内壁为抛光型芯针面；拉手槽 SPI B-1；内表面常规省模 |
| 拔模 | 咬花面按咬花厂对所选纹号的建议加拔模角（经验值：每 0.025 mm 纹深加约 1°–1.5°） |
| 颜色 | 签样色板。测色按 GB/T 3979-2008，色差按 GB/T 7921-2008。建议起点：A 面 ΔE*ab ≤ 1.0，B 面 ≤ 2.0（建议值，双方约定）。在 D65 和 TL84 两种光源下检查同色异谱 |
| 光泽 | 本色面按 GB/T 8807-1988 测 60° 光泽，以签样板实测值为基准，容差双方约定 |
| 检测 | ① **耐化学品**：洗洁精、碱性重油污清洁剂、白醋、含氯消毒液、食用油，擦拭或滴放后无变色、无失光、无开裂（方法和条件双方约定）<br>② 恒定湿热 GB/T 2423.3-2016 后外观无变化<br>③ **防霉**：参考 ISO 846<br>④ **耐黄变**：热老化，条件双方约定<br>⑤ 外观检验：A/B/C 面分别判定，黑点、流痕、熔接线按限度样 |
| 风险与对策 | 1,056 个孔会形成大量熔接线 → 做模流分析，优化浇口位置，用咬花遮盖<br>多个零件同用一个白色、来自不同模具 → 同牌号、同色母、同批次；A 面和 B 面分别签限度样<br>灯座件靠近 LED 时会漏光 → 暗室亮灯检查 |

## 11. 渲染要表达什么

配套的《keyshot_render_prompt_旗舰质感版.md》会把本方案转换成 KeyShot 执行参数。渲染图要回答四个问题：

1. **它是什么**：厨房里的瓷罐式空气产品，而不是音箱、保温杯或香薰机。
2. **它质感怎么样**：瓷白温润细腻，金属顶冷静精密。
3. **它在橱柜里是什么样子**：橱柜情境图，表现暗处可见、状态一眼可读。
4. **它怎么工作**：爆炸图里的颜色分组，让人看懂空气路径和哪里可以动手。
